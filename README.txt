موقع عيادة سيف الدين محمد علي — قرية الرواشدة، القضارف

نسخة البداية المجانية:
- index.html: موقع عربي متجاوب مع بوت أسئلة شائعة يعمل مباشرة في المتصفح ولا يحتاج API أو مفتاحاً مدفوعاً.
- البوت يجيب عن معلومات العيادة والأسئلة الشائعة المحدودة فقط؛ ليس ذكاءً اصطناعياً عاماً ولا يقدم تشخيصاً أو وصفات.
- server.mjs وpackage.json و.env.example: ملفات اختيارية للنسخة المتقدمة إذا رغبت لاحقاً بربط خدمة ذكاء اصطناعي. لا تحتاجها لنشر نسخة الأسئلة الشائعة المجانية.

طريقة النشر المجاني المقترحة:
1. فك ضغط الملف على جهازك.
2. ارفع ملف index.html وحده كصفحة ثابتة إلى خدمة استضافة صفحات مجانية مثل Cloudflare Pages أو Render Static Site.
3. لا ترفع مفاتيح API أو ملفات .env إلى موقع عام.
4. اختبر رابط الموقع وزر طلب الموعد قبل مشاركته.

ملاحظات مهمة:
- رقم واتساب الموجود بالموقع يحتاج تأكيداً من صاحب العيادة قبل النشر.
- ساعات العمل غير محددة حالياً.
- طلب الموعد ليس تأكيداً للحجز.
- لا تطلب من الزائر إرسال بيانات طبية حساسة. الحالات الخطرة تحتاج الرعاية العاجلة.
